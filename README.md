# 🌌 VANGUARD TERMINAL [v3.9.7]

A high-performance personnel intelligence and division tracking system for Roblox-based tactical organizations.

## 🚀 CORE CAPABILITIES

### 🔍 Deep Recon Intelligence
- **IntelCache™ Architecture**: Persistent server-side storage for scanned personnel data.
- **RoTunnel Protocol**: High-throughput uplink via rotating proxy for rate-limit suppression.
- **Outfit Matrix**: Paginated gallery support for personnel with high-volume customization (up to 500+ records).
- **Badge Pinpoint Walker**: Specialized recursive cursor walking for precise badge tallying.

### 🛡️ Tactical Asset Management
- **Division Tracking**: Real-time synchronization with Roblox group structures.
- **Unit Scanning**: Automated data extraction for target usernames or IDs.
- **RoTector Integration**: Direct risk-level assessment via external security endpoints.

### 📊 Administrative Tools
- **Google Sheets Sync**: Automated log synchronization for operational history.
- **Audit Logging**: Comprehensive action tracking for all high-tier reconnaissance.
- **Version Control**: Built-in historical log of system updates and stabilization patches.

## 🛠️ TECH STACK

- **Backend**: Node.js / Express
- **Database**: MongoDB (via Mongoose)
- **Frontend**: Clean Tactical CSS / Vanilla JS
- **Uplink**: RoTunnel / Axios
- **Auth**: JWT-based Secure Uplink

## 📡 DEPLOYMENT

The system is configured for cloud deployment with automated build pipelines.

1. Ensure `.env` is configured with necessary Roblox credentials and Database URI.
2. `npm install` to synchronize dependencies.
3. `npm run start` to initialize the operational terminal.
